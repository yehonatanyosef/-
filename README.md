# 🏝️ אי האנגלית – English Island

משחק ללימוד אנגלית לילדים בגילאי 5–10. הממשק בעברית, והתוכן באנגלית.
המשחק בנוי כמסע במפה של איים: כל אי עוסק בנושא אחר, ובכל אי יש שלבים ואתגר בוס בסוף.

## הרצה

```bash
npm install
npm run dev      # שרת פיתוח
npm run build    # בנייה לפרודקשן (תיקיית dist)
npm test         # בדיקות יחידה למנוע
```

מומלץ להשתמש ב-Chrome או ב-Edge. הם תומכים גם בהקראה קולית וגם בזיהוי דיבור.
ב-Safari ההקראה עובדת, אבל תרגילי הדיבור מוסתרים אוטומטית.

## מה יש במשחק

- **בדיקת רמה מסתגלת**: 10 שאלות. כל תשובה נכונה מעלה את רמת הקושי, וכל טעות מורידה אותה.
  לפי התוצאה (רמה 1 עד 5) הילד מתחיל באי המתאים. האיים הקודמים נפתחים, והמילים שבהם נכנסות לחזרה.
- **10 איים**: אותיות, חיות, צבעים ומספרים, אוכל, בית ומשפחה, טבע, גוף ובגדים, פעלים ותארים, משפטים וסיפורי קריאה.
  יש בסך הכול כ-60 שלבים, כ-150 מילים, 24 משפטים ו-8 סיפורים עם שאלות הבנה.
- **21 סוגי תרגילים**: האזנה ובחירה, קריאה, תרגום, אות ראשונה, אות חסרה, איות באריחים, הקלדה,
  דיבור במיקרופון, משחק זיכרון, בניית משפט, התאמת משפט לתמונה ושאלות על סיפור.
- **מנוע מסתגל**: מדד יכולת (1–5) מתעדכן אחרי כל שלב. לפיו נקבעים מספר האפשרויות, הרמזים בעברית,
  ההקראה האוטומטית וסוגי התרגילים. אחרי טעות, השאלה חוזרת בסוף השלב בגרסה קלה יותר.
  ילד שמתקדם מהר יכול לקפוץ ישר לבוס 🚀.
- **חזרה מרווחת (Leitner)**: כל מילה מקבלת מועד חזרה. מילים שהגיע זמנן משתלבות בשלבים ובמסך "תרגול".
- **מוטיבציה**: כוכבים (1 עד 3), מטבעות, נקודות ניסיון, רצף ימים, יעד יומי, רצף תשובות נכונות 🔥, 16 הישגים,
  חנות עם חברים למסע, קונפטי וצלילים.
- **לוח הורים** (מוגן בתרגיל כפל): רמה, מילים שנלמדו, דיוק בכל מיומנות, פעילות בשבועיים האחרונים,
  מילים לחיזוק, הגדרות, בדיקת רמה מחדש ואיפוס.
- כמה פרופילים של ילדים על אותו מכשיר. הנתונים נשמרים במכשיר, ואפשר להוסיף גיבוי לקובץ או סנכרון בענן (ראו בהמשך).

## גיבוי וסנכרון בענן

**גיבוי לקובץ** עובד תמיד. בלוח ההורים לוחצים "שמירת גיבוי" ו"שחזור מגיבוי".
השחזור מאחד את ההתקדמות ולא מוחק כלום.

**סנכרון בענן** (אופציונלי): ההורה פותח חשבון באימייל וסיסמה, וההתקדמות של כל הילדים
נשמרת בענן ומתעדכנת אוטומטית בכל המכשירים. כך מפעילים אותו:

1. פותחים פרויקט חינמי ב-[supabase.com](https://supabase.com).
2. ב-SQL Editor מריצים את התוכן של `supabase/schema.sql`. הקובץ יוצר טבלה, וכל הורה רואה בה רק את הנתונים שלו.
3. מעתיקים את `.env.example` לקובץ `.env.local` וממלאים את `VITE_SUPABASE_URL` ואת `VITE_SUPABASE_ANON_KEY`
   (נמצאים ב-Project Settings → API).
4. מריצים מחדש `npm run dev` או `npm run build`. בלוח ההורים יופיע טופס התחברות.

איך הסנכרון עובד:
- הנתונים בכל מכשיר נשמרים כרגיל, כך שהמשחק עובד גם בלי אינטרנט.
- כמה שניות אחרי כל שינוי, וכשחוזרים לאפליקציה, ההתקדמות מתאחדת עם הענן.
- האיחוד לא מאבד התקדמות משני המכשירים: מילים, כוכבים, הישגים ונקודות נשמרים מכולם.
- ערכים שיכולים גם לרדת, כמו מטבעות וחבר נבחר, נלקחים מהעותק שהשתנה אחרון.
- מחיקת שחקן ואיפוס התקדמות עוברים גם הם לשאר המכשירים.

## מבנה הקוד

```
src/data/       תוכן: מילים, אותיות, משפטים, סיפורים, איים, חברים
src/engine/     לוגיקה: יצירת שיעורים, בדיקת רמה, חזרה מרווחת, התקדמות, הישגים, דיבור, צלילים, סנכרון
src/hooks/      useCloudSync – סנכרון אוטומטי עם הענן
supabase/       סכמת מסד הנתונים לענן
src/exercises/  רכיבי התרגילים
src/screens/    מסכים: פרופילים, בדיקת רמה, מפה, שיעור, תוצאות, חנות, הורים
```

כדי להוסיף תוכן, מוסיפים שורות ל-`src/data/words.ts` (או לקובצי המשפטים והסיפורים).
השלבים נבנים אוטומטית מהנתונים.
